细节放大 & 备选方案

角标规格：14×14px · 圆角 4px · 字号 9px 加粗，位于日期数字右侧；实现时颜色走主题令牌（--holiday-fg / --work-fg 等）
假期首日：日期 + [休] + 红色「节日名」
调休上班日（含今天）：日期 + [班]，悬浮显示补哪天假
备选方案 B：整格浅红底纹（更醒目，但与任务彩色底/多皮肤易冲突，不推荐默认）
  • 数据来源：内置国办安排静态表（src/lib/holidays.ts，覆盖 2025–2027，可随版本更新），离线可用、不引外部依赖。
  • 展示规则：每个放假日显示「休」角标；每个补班日显示「班」角标；红色节日名只在假期第一天出现，避免格子过挤。
  • 悬浮气泡：显示「节日名 + 放假区间/天数 + 哪几天补班」，鼠标移出消失，不占用格子空间。
  • 联动范围：月视图格子；日期详情弹窗标题、悬浮窗后续可复用同一数据源（本次先做月视图）。
